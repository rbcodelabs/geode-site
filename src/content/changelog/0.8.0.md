## What's New in v0.8.0

This release adds Mermaid diagram support, makes Live Preview tables genuinely
readable and editable, and fixes hotkeys being swallowed inside Web Viewer tabs.

### Features

- **Mermaid diagrams** — ` ```mermaid ` code blocks now render as real diagrams in
  both Live Preview and Reading view. Diagrams follow the active light/dark theme
  (colors are derived from Geode's own CSS variables, so community themes carry
  through), `internal-link` nodes are clickable and navigate to the linked note,
  and clicking into a block reveals its raw source to edit then re-renders when you
  click out. A malformed diagram shows an inline error instead of breaking the rest
  of the note.

  The Mermaid library is **loaded lazily on first use** from a separate bundle
  chunk, so it costs nothing until a diagram is actually on screen — the cold-start
  renderer bundle grew by only 0.4%. Plugins can reach the same memoized instance
  through `loadMermaid()` on the `obsidian` compatibility module, so a plugin's
  `mermaid.initialize()` and Geode's own diagrams can't diverge. (#131)

- **Inline markdown in Live Preview table cells** — table cells now render their
  inline markdown (bold, italic, code, links) instead of showing raw syntax, and
  long cell contents wrap onto multiple lines rather than forcing the whole row to
  overflow horizontally. Clicking into a cell still reveals the raw source to edit.
  (#132)

### Bug Fixes

- **Hotkeys work inside Web Viewer tabs** — app hotkeys (command palette, quick
  switcher, tab switching, and the rest) were being swallowed by the embedded page
  whenever focus was inside a `<webview>` tab, effectively trapping keyboard
  navigation until you clicked back out. Key events from guest pages are now routed
  back to the host and dispatched against the normal command system. (#130)

### Notes

- **Version jump:** this is a minor bump (0.7.x → 0.8.0) rather than a patch,
  because Mermaid rendering is a substantial new user-facing capability that pulls
  in its own (lazily loaded) dependency.
- **Install:** these macOS builds are ad-hoc signed but **not notarized**, so
  Gatekeeper still warns on first launch of a downloaded copy. See the
  [Install section of the README](https://github.com/rbcodelabs/geode#install)
  for the one-time workaround.
- No migration steps and no breaking changes — existing vaults, plugins, and
  themes work unchanged.
