## Features

- **Connect GitHub to Geode** — sign in from Settings → GitHub using a device code, view the repositories granted to the Geode GitHub App, and disconnect when needed. No personal access token or client secret is required. (#308)
- GitHub credentials are encrypted with the OS keychain. Expiring user access tokens refresh on demand, with a reconnect prompt when authorization expires or is rejected. Connecting is disabled if secure storage is unavailable. (#308)

## Notes

- This release adds the Geode connection and an on-demand token API. Agent Threads does not yet receive these credentials automatically; container GitHub tools and commit identity configuration are follow-up work.
- Disconnect removes local credentials. To fully revoke access, use the linked GitHub application settings page.
- macOS downloads support Apple Silicon and are Developer ID signed, notarized, and stapled.
