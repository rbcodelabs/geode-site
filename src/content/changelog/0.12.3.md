## What's New in v0.12.3

### Features
- **Reveal in Finder / Show in system explorer** — right-click a file or folder in the File Explorer, or open a document tab's "More options" menu, to highlight it in the OS file manager, matching Obsidian's behavior. Desktop-only. (#172)
- **External project roots — design foundation.** Accepted ADR-0015 and the Phase 1 design for core-managed, read-only external project roots with stable identities, laying the groundwork for attaching folders outside the vault. This release ships the underlying registry only (persistence, read-only grants, overlap protection, composite Project bindings) — there is no user-facing UI yet. (#171, #173)

### Bug Fixes
- **`npm run parity:check` failed with a raw stack trace when its external doc corpora were missing** (e.g. after macOS clears `/tmp`), instead of explaining what was missing or how to fix it. It now fails with an actionable message: every missing corpus, the `git clone` command to restore it, and the relevant override flags. (#175)
- Refreshed the checked-in Obsidian compatibility ledger, which had also gone stale independently of the above. One new requirement was picked up (Bases' native Kanban layout), left classified `unknown` pending its own assessment. (#175)

### Notes
- No breaking changes or migration steps.
- The external root registry (#173) is an internal foundation only — no IPC, File Explorer UI, or Threads integration yet; those land in follow-up work.
