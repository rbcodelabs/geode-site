## What's New in v0.5.14

### Bug Fixes

- **Restored background metadata indexing** — Geode's packaged metadata indexer now starts correctly as an Electron utility process instead of crashing at launch. This prevents the renderer from falling back to indexing the entire vault itself, eliminating the sustained high-CPU startup regression introduced in v0.5.13. ([#69](https://github.com/rbcodelabs/geode/pull/69), closes [#67](https://github.com/rbcodelabs/geode/issues/67))

### Notes

- No settings, data migrations, or workflow changes are required.
- This patch contains only the metadata indexer startup fix.
- macOS installers are available for Apple Silicon and Intel. Builds are ad-hoc signed but not notarized.
