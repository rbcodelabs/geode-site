## What's New in v0.10.0

### Features

- **Native iOS MVP shell** — Geode now includes a Capacitor-based iPhone and iPad application shell with native managed-vault access, Files-folder selection, atomic note writes, reconciliation, and exact-byte persistence across relaunches. (#137)
- **Touch-first workspace** — Phone navigation moves to a safe-area-aware five-action bottom bar, while phone and tablet layouts provide responsive Files, Search, Details, Settings, editor, Graph, Canvas, and Bases experiences. (#137)
- **Mobile Graph, Canvas, and Bases** — Core power views now support touch selection, pan and pinch gestures, authoring, editing, save recovery, conflict preservation, and bounded mobile rendering. (#137)
- **Mobile community-plugin runtime** — Compatible plugins can run through a bounded mobile admission and lifecycle layer with restricted module resolution, quarantine, restart, and rollback behavior. (#137)

### Bug Fixes

- **iPhone and iPad layout safety** — Controls and editor content remain inside native safe areas, including after iPad rotation and Details drawer transitions. (#137)
- **Canvas media lifecycle** — Pending image, audio, and video loads are detached before their blob URLs are revoked, preventing intermittent missing-media errors during rerender and reload. (#137)
- **Managed-vault continuity** — Root note discovery, legacy managed-vault migration, process-relaunch persistence, and delayed WKWebView interactions are covered by a repeatable native acceptance gate. (#137)

### Improvements

- Desktop Electron behavior remains behind the existing desktop host while shared renderer capabilities move behind typed platform services.
- The compatibility ledger is refreshed to 2,852 tracked requirements.
- Release evidence now includes 1,283 unit tests, 156 Electron journeys, 43 mobile Chromium journeys, and three clean native simulator iterations (84 native tests total).

### Notes

- This GitHub release publishes the existing ad-hoc-signed macOS installers for Apple Silicon and Intel.
- The iOS MVP is included as source and simulator-tested native project infrastructure; v0.10.0 does not publish a TestFlight or App Store build.
- Physical File Provider coverage, physical-device accessibility/performance validation, and a reviewed real community-plugin lifecycle remain follow-up release gates for broader iOS distribution.
