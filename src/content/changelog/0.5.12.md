## What's New in v0.5.12

### Performance Improvements

- **Faster, smoother tab activation** — hidden fixed sidebar views no longer render synchronously whenever a file opens. In particular, a hidden Backlinks pane no longer performs its vault-wide unlinked-mentions scan inside every tab activation, preventing that invisible work from delaying tab controls, hover states, and other window animations. ([#64](https://github.com/rbcodelabs/geode/pull/64))
- **Deferred sidebar views stay accurate** — hidden views continue tracking the active file and refresh through their normal open path when revealed. Backlinks still refreshes immediately while visible, and queued metadata updates re-check visibility before rendering.

### Measured Results

In a disposable 100 MB, 1,000-note vault, PR #64 reduced median direct leaf activation from **13.6 ms to 0.6 ms**, median click activation from **25.8 ms to 0.7 ms**, and the hidden Backlinks listener from **12.9 ms to 0 ms**. The deferred Backlinks calculation runs when the pane is explicitly revealed.

### Reliability

- Added an Electron regression test covering hidden file activations, queued metadata events, reveal-time rendering, and continued refreshes while Backlinks is visible.
- Release validation passed **694 unit tests across 57 files** and **36 Electron E2E tests**, along with TypeScript checking, production bundling, and macOS x64/arm64 packaging.

### Notes

- **No breaking changes or migration steps.** Existing vaults, settings, plugins, and themes require no changes.
- macOS builds remain ad-hoc signed and are not notarized; the first-launch Gatekeeper instructions remain in the README.
