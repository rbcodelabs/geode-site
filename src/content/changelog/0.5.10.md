## What's New in v0.5.10

### Performance

- **Background metadata indexing** — Geode now performs vault file reads, Markdown parsing, cache serialization, and atomic cache persistence in an Electron utility process, keeping this work off the renderer thread for a more responsive experience in larger vaults. Cache writes are debounced, unchanged files are reused on warm startup, and Geode falls back safely if the background process fails. (#62)

### Bug Fixes

- **Plugin file links no longer blank the Geode window** — Absolute vault-file links rendered by plugins, including links inside shadow DOM, now open safely in a Geode workspace leaf at the requested line and column. Valid files outside the vault open with the operating system, while malformed and unsafe targets are rejected. (#61)

### Notes

- No migration or configuration changes are required.
- macOS builds remain ad-hoc signed and are not notarized.
