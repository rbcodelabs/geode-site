## What's New in v0.5.16

### Critical crash fix

- **Large vaults no longer crash during metadata initialization** — Geode previously transferred the complete metadata cache as one Electron IPC object. On an 8,299-file vault, the 274 MB cache drove Electron's structured-clone allocator toward a 2.96 GB allocation and terminated both the metadata utility and renderer processes.
- **Bounded metadata transport** — initialization now streams ordered chunks capped at 256 KiB and 50 entries instead of sending one monolithic snapshot.
- **Safe startup behavior** — live file changes are preserved while chunks arrive, individually oversized files are read normally, and utility failure falls back without transferring or rewriting the complete cache through IPC.

### Verification

- The actual affected 274 MB cache initialized in 2.98 seconds with both processes alive and zero renderer errors.
- 712 unit tests and 38 Electron end-to-end scenarios passed.

Full change: [#71](https://github.com/rbcodelabs/geode/pull/71)
