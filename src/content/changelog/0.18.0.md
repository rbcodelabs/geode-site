# Geode v0.18.0 — shared wiki foundations

## Features and improvements

- Shared, Electron-independent metadata and link primitives provide a foundation for wiki tooling. The Phase 0 database proof is engineering evidence, not a hosted service. (#190)
- Internal read-only Node snapshots support bounded folder capture, metadata, literal search, link resolution and backlinks, with ambiguity and incomplete parsing reported explicitly. No public SDK, write API or sync service is introduced. (#195)
- Desktop navigation and Node queries now share link-candidate selection while preserving their distinct compatibility policies. This is a link-resolution milestone, not a full desktop backend migration. Current-main Canvas media restoration fixes are retained. (#196)
- Synthetic linked/dense vault generation and paired benchmarks make large-vault behavior reproducible without using personal notes. (#204)
- Benchmark safeguards wait for terminal indexing readiness, monitor owned processes independently and retain failed/partial measurements rather than replacing them. (#210)
- Desktop metadata cache loading uses bounded snapshot pages with expiry and cancellation; live edits and deletions take precedence. Database initialization is ordered before the utility indexer starts. (#211)

## Important limitations

- This release is **not a blanket performance improvement**. In the three-pair synthetic comparison, 10,000-note warm readiness increased by paired medians of approximately 2.6 seconds (linked) and 11.9 seconds (dense).
- At 50,000 notes, all linked-workload samples failed on both revisions. All three dense candidate samples passed while all three dense baseline samples failed. These results do not establish reliable support for arbitrary 50,000-note vaults. Renderer-watchdog recovery and further indexing/rendering bottlenecks remain unresolved.
- No vault format or schema migration is introduced. Desktop's legacy explicit-dot-relative metadata behavior is preserved; navigation and graph resolution can differ for `./` links.
- macOS Apple Silicon and Intel installers are ad-hoc signed, not notarized. Native packaged runtime verification was performed on Apple Silicon; Intel packaging/signature checks are not Intel runtime testing.
- The optional application updater remains disabled by default. Existing dependency advisories include its YAML metadata parser; do not interpret this release as qualification of updater opt-in or privileged third-party plugin protocol handlers.
- Packaged image checks verified actual decoding, but initial image-placeholder CSP console warnings remain. Mobile browser regression is not native iOS release qualification.
