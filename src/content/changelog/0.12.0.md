## What's New in v0.12.0

### Features

- **Per-tab document navigation history** — use the back and forward controls independently in each Markdown, Canvas, or Base tab. History is session-only, skips deleted files, preserves each view's live identity, and stays consistent when loads fail or navigations overlap. ([#165](https://github.com/rbcodelabs/geode/pull/165))
- **Toggleable Web Viewer core plugin** — enable or disable Web Viewer per vault from Settings. Disabling it safely preserves open browser tabs as placeholders and restores the same tabs and URLs when re-enabled, including after restart. Commands, links, local HTML files, and unsupported/mobile hosts now follow the plugin's actual availability. ([#166](https://github.com/rbcodelabs/geode/pull/166))

### Improvements

- Updated the public feature documentation to describe per-tab navigation history and the Web Viewer lifecycle, and refreshed all visible version examples for v0.12.0. ([documentation commit](https://github.com/rbcodelabs/geode/commit/e68be471c39b9ca0124d4ac7fc650fe523db5492))

### Notes

- Document history is intentionally not persisted between app sessions.
- Web Viewer remains enabled by default. Its setting is stored separately for each vault.
- macOS builds are ad-hoc signed but not notarized; the existing Gatekeeper guidance in the README still applies.
