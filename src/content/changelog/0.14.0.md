## What's new in v0.14.0

### External Project folders

- Browse Claude Threads Project folders directly in a separate Projects section
  of Geode's File Explorer. Explicitly attach a folder on macOS, expand its tree,
  and open UTF-8 text files up to 2 MiB in a distinct read-only source tab. (#176)
- Project creation, renaming, working-directory changes, and deletion stay in
  sync with the explorer. Granted source tabs can restore across app restarts.
- Manage inactive Project associations and unassigned grants in Settings →
  Project folders. Removing a record never deletes external files or changes
  an agent's working directory.

### Safety and limitations

- Existing working directories do not grant access automatically. Attachment
  and reconnect require explicit confirmation; directory symlinks cannot be
  traversed, and file symlinks must remain inside the granted root.
- External files remain read-only, with manual Refresh and no filesystem
  watcher, indexing, search, autosave, or rendered Markdown. Vault wikilinks,
  backlinks, metadata, TFile, and existing Obsidian plugin APIs are unchanged.
- Mobile displays Project labels with “Available on desktop”; external folder
  access and external contents synchronization are not included.
- Opt-in study events and the in-product feedback prompt are deferred to a
  follow-up. This release adds no study data collection.
- macOS builds are ad-hoc signed, not notarized. See the installation guidance
  in the README if Gatekeeper blocks a manually downloaded app.
