## What's New in v0.7.19

### Bug Fixes

- **Theme-compatible plugin controls and Canvas colors** — defines Obsidian's documented semantic color variables so plugins such as Claude Threads can render colored controls reliably, including the stop button. Canvas color tokens now resolve from the same theme palette. (#127)
- **Correct macOS window chrome** — aligns the ribbon and sidebar with the native traffic-light area in windowed mode, removes that clearance in fullscreen, and restores it correctly when leaving fullscreen. The top-left titlebar gutter and native rounded window background now follow the active theme. (#112)
- **Readable links in hosted plugin panes** — ordinary links rendered by plugins such as Claude Threads now use Obsidian's global theme link colors, decoration, weight, and hover states instead of Chromium's raw blue styling. (#112)

### Notes

- No migration or configuration changes are required.
- macOS builds remain ad-hoc signed and are not notarized; the existing first-launch Gatekeeper instructions still apply.
