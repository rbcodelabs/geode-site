## What’s New in v0.10.4

### Critical Bug Fix

- **Prevent runaway metadata-cache growth and out-of-memory failures** — notes containing self-referencing YAML frontmatter can no longer poison metadata-cache writes, abort initial reconciliation, or trigger repeated write retries that grow the SQLite WAL. Affected circular values degrade safely while ordinary shared YAML aliases retain their data. ([#146](https://github.com/rbcodelabs/geode/pull/146))
- **Preserve cache transaction safety** — genuine SQLite write failures still roll back and retry with the complete dirty batch instead of silently committing partial cache state.

### Notes

- No vault migration or user action is required. Geode rebuilds or updates metadata cache entries normally.
- Release metadata was finalized in [#148](https://github.com/rbcodelabs/geode/pull/148).
- macOS installers are ad-hoc signed but not notarized; follow the first-launch instructions in the README.
