## Design artifacts — Phase 1

Geode can now safely open static UI artifacts created by Claude Threads.

### Highlights

- Isolated ArtifactView with a dedicated `geode-artifact://` origin
- Live reload as artifact source files change
- Desktop, tablet, and mobile viewport controls
- Runtime diagnostics and PNG capture
- Artifact and viewport restoration after relaunch
- Strict versioned manifests with actionable validation errors

### Security

Artifacts run in an ephemeral, Node-less guest. Network access, clipboard access, downloads, popups, external navigation, preload scripts, and persistent guest storage are denied. File resolution is contained to the real artifact root, including symlink-escape protection.

### Installation note

The macOS builds remain unsigned and unnotarized. macOS may require the documented first-launch Gatekeeper workaround.
