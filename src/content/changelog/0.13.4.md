## Bug fixes

- Preserve plugin-owned companion splits across workspace restoration and plugin reloads. When a destination tab closes but sibling tabs remain, the next contextual item opens in a replacement tab in the same split. (#184)
- Preserve companion ownership when its destination moves, and normalize duplicate saved ownership without removing tab content.

## Compatibility

Agent Threads 0.35.1 uses this support for conversation-first navigation. Existing layouts remain supported; unmarked panes from older versions are not automatically adopted and may need one-time manual cleanup.

macOS installers are provided for Apple Silicon and Intel. Builds remain ad-hoc signed and are not notarized, as in previous releases.

## Known issue

A pre-existing Canvas media restoration race can leave an image blank when restoring multiple tabs. The release verification reproduced this on unchanged 0.13.3 as well as the patch branch. The full desktop suite passed 211 tests, including both companion lifecycle scenarios, with this one Canvas test failing.
