## Bug fixes

- Vault refresh now skips hidden development trees, preventing worktree contents from triggering misleading provider-unavailable errors. Strict sync scanning remains unchanged. (#274)

## Improvements

- Refresh failures now show a compact banner with Retry and an on-demand details dialog. Cause-specific guidance distinguishes permission problems, unavailable content, missing paths and unsupported links. Safe diagnostic copying omits note content and absolute personal paths. Saving-paused warnings stay visible, and failed scans preserve the previous file list. (#274)
- Desktop voice plugins can use Geode's packaged PCM AudioWorklet to capture audio off the UI thread without allowing blob scripts. Microphone permissions and stream ownership remain with the plugin. This support was already merged on main after v0.23.0. (#273)

## Notes

- macOS Apple Silicon only. Installers are Developer ID signed, notarized and stapled.
- Existing signed installations can use **Help → Check for Updates…**. Manual installers are available below.
- Passkey/WebAuthn PRs #245 and #246, and Templates PR #275, are not included.
- Verification: final release CI passed 3,535 units and 336 desktop tests, with two skips and no retries; mobile browser harness 46 passed. The revised dialog was exercised in a visible Electron session and its shared QA screenshots were reviewed.
