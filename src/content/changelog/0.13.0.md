## Features

- Add passage-anchored Markdown comment threads: select ordinary prose to comment, reply, edit or delete messages, resolve and reopen discussions, and reattach detached anchors. Comments travel inside the note without an account or sidecar file. ([#179](https://github.com/rbcodelabs/geode/pull/179))
- Show human/agent attribution and expose the comments service through the Geode plugin API, including a stable `require("geode")` namespace on desktop and mobile.

## Improvements

- Live Preview and Reading view hide valid comment markers; Source mode keeps the underlying Markdown accessible. Search and metadata retain correct source positions, and normal Enter-key editing works inside anchored text.
- Anchor validation protects Markdown and Geode syntax, including code, links, math, highlights, and Obsidian comments. Malformed comment markers are preserved and block comment mutations instead of risking note damage.
- Add a Markdown comments guide and an architecture decision explaining storage and write-safety tradeoffs.

## Notes

- Comments are encoded in the Markdown file, **not encrypted**. Sharing the file shares its comments and attribution.
- After directly editing anchored prose, reopen the note if the Comments pane preview or detached status is stale.
- Closed-file comment writes check current provider content, but external edits between the read and write remain possible without host-level compare-and-swap support.
- macOS downloads are available for Apple Silicon and Intel. Builds are ad-hoc signed, not notarized; see the [installation guide](https://github.com/rbcodelabs/geode#install) for first-launch instructions. This release does not add a public iOS download.
