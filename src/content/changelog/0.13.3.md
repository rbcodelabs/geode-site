## Bug fixes

- Fixed false renderer-crash recovery after the computer sleeps. Geode now pauses heartbeat hang detection during suspension and grants a fresh grace period on wake, so sleep does not unnecessarily disable community plugins. Genuine renderer crashes and hangs still recover normally. (#183)

## Validation

- 1,771 unit tests and 210 Electron E2E tests passed, including simulated sleep/wake regression coverage.
- Physical macOS sleep/wake validation remains to be performed.

## Downloads

macOS installers are available for Apple Silicon (arm64) and Intel. Builds are ad-hoc signed and not notarized; see the README for installation instructions.
