## What's New in v0.5.0

### Features
- **Run real community plugins that use editor autocomplete + task queries.** A three-part plugin-API push lands full compatibility for plugins like **obsidian-tasks**:
  - **`EditorSuggest` + `Scope` + `app.scope`** are now exported and wired up, so plugins that subclass `EditorSuggest` at module-eval time (obsidian-tasks, linear-integration) load instead of crashing with "Class extends undefined". (#50)
  - **Frontmatter tag helpers, `metadataTypeManager`, and `isShown`** — the metadata/query surfaces obsidian-tasks touches now behave Obsidian-faithfully, so a ` ```tasks ` block renders its full query widget (filters, copy controls, live count) with zero console errors. (#51)
  - **`listItems` + `sections` parsing, indexed before layout-ready** — the last mile: a ` ```tasks ` query now renders the **actual matching tasks** from your vault (verified against real obsidian-tasks v7.23.1). (#53)

### Improvements
- **New app icon** — replaced the placeholder with a polished amethyst-geode design, sized to the standard macOS icon grid with a beveled squircle edge. (#52)

### Notes
- macOS builds are **ad-hoc signed but not notarized** — first launch needs a right-click → Open (or `xattr -dr com.apple.quarantine /Applications/Geode.app`). See the README for details.
- In-app **auto-update** (electron-updater, #41) is still in review and intentionally **not** included in this release — you'll update these builds manually for now.
