## Features

- **Team-friendly installer and updater** ([#162](https://github.com/rbcodelabs/geode/pull/162)) — install or update Geode from the public GitHub release using the documented `scripts/geode-update.mts` command, without the GitHub CLI or a GitHub account. The script also re-signs the downloaded app locally to address macOS's “damaged app” warning and makes a best-effort backup of Claude Threads plugin data before replacement.
- **Custom defaults for fresh vaults** ([#163](https://github.com/rbcodelabs/geode/pull/163)) — organization-specific builds can seed a default community theme and plugin set on the first opening of a new vault by supplying resources at build time. The upstream Geode build ships no default theme or plugin list, so existing users and previously opened vaults are unchanged.

## Improvements

- Expanded installation documentation with the one-command updater, safe `--check` mode, version selection, user-local installation, and manual Gatekeeper recovery guidance.

## Notes

- No data migration or configuration change is required.
- The updater script requires macOS and Node.js 23.6 or newer.
- Release artifacts include Intel and Apple Silicon DMG and ZIP installers plus update metadata.
- Builds remain ad-hoc signed and are not notarized; see the README installation guidance.
