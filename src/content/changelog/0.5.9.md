## What’s New in v0.5.9

### Bug Fixes

- **Workspace controls stay reachable when many tabs are open** — At narrow window widths, Geode now keeps tabs within the available header space instead of allowing the tab strip to push sidebar controls off-screen. Excess tabs move into the tab-list menu, the active tab remains visible, and visible tabs retain a usable minimum width. ([#60](https://github.com/rbcodelabs/geode/pull/60))

### Notes

- No migration or configuration change is required.
- macOS packages remain ad-hoc signed and are not notarized; follow the existing README instructions for first launch.
