## What's New in v0.7.0

### Features

- **Expanded Canvas authoring** — create and edit text, note, media, web, and group cards; author, label, reconnect, color, and remove edges; and drag vault files, folders, or browser URLs directly onto a Canvas. (#79)
- **Advanced Canvas workflows** — marquee and multi-selection, duplication, alignment snapping, grouping, resize controls, camera shortcuts, undo/redo history, semantic search, backlinks, Markdown embeds, and isolated live web previews make Canvas substantially more capable. (#79)
- **Documented compatibility baseline** — a generated, evidence-backed parity ledger now tracks 2,850 public Obsidian requirements and foundational public API contracts. The ledger is a coverage baseline, not a claim of complete compatibility. (#79)

### Bug Fixes

- **Malformed Canvas recovery** — invalid Canvas files now open in a non-destructive recovery view without exposing stale-document mutation paths. (#79)
- **Reliable wake recovery** — system sleep no longer makes a healthy renderer heartbeat appear stale and trigger false renderer recovery immediately after wake. (#78)
- **Safe external file dragging** — dragging an external file over the workspace no longer activates pane-split targeting or creates an unintended split. (#80)

### Notes

- Inline note editing inside Canvas cards, native PDF previews, and some broader Canvas context/action workflows remain incomplete.
- macOS builds remain ad-hoc signed and unnotarized. Follow the first-launch instructions in the README if Gatekeeper blocks the app.
- Windows and Linux installers are not included in this release.
