## Highlights
- **Onboarding checklist** – a new core plugin that tracks setup progress in the right sidebar and opens automatically when steps are outstanding. Other plugins can register their own recommended steps. New vaults also get a recommendation to install and enable **Agent Threads** in one click.
- **Audio recorder** core plugin.
- **Quick switcher** gains a web search row and a plugin row provider API.
- **Focus pane** – temporarily maximize one tab group.
