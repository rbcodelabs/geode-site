## What's New in v0.5.13

### Reliability

- **Safe plugin failure containment** — Geode now attributes exceptions at plugin-owned lifecycle, command, DOM, and view boundaries, quarantines only the offending plugin, and lets you restore it from Settings.
- **Renderer crash recovery** — if the renderer crashes, Geode records durable diagnostic context and opens a replacement window once with community plugins suppressed, preserving the enabled-plugin configuration and offering a visible **Restart with plugins** action.
- **Crash-loop protection** — recovery state prevents repeatedly relaunching a broken plugin set while keeping the path back reversible.

### Quality

- Added focused unit coverage for the bounded crash journal and plugin quarantine behavior.
- Added Electron E2E coverage for plugin quarantine/restore and a real renderer `process.crash()` recovery.
- Documented the containment boundary and known limitations in ADR 0003.

### Known limitations

- Shared-renderer infinite loops, out-of-memory failures, and native crashes cannot be contained in-process; recovery restarts with community plugins suppressed.
- Generic event and already-created timer callbacks remain unattributed when plugin ownership metadata is unavailable.

Full change: [#65 — Recover safely from plugin and renderer crashes](https://github.com/rbcodelabs/geode/pull/65)
