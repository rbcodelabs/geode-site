## Bug fixes

- Vault images now open in a dedicated read-only image tab instead of the Markdown editor. This works from File Explorer, Markdown links, and plugins. Images fit within the pane, preserve normal tab navigation and background focus, and restore after relaunch. (#193)
- Image resources are released when an image changes or its tab closes.

## Validation notes

The image-opening and workspace-restore tests passed, along with 2,040 unit tests and 231 Electron tests. One existing graph-view tab-count test failed; a Web Viewer settings test passed on retry, and one integration test was skipped. This patch was approved with that documented test exception.

macOS builds are ad-hoc signed but not notarized. Apple Silicon and Intel installers are provided.
