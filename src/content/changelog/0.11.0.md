## What's New in v0.11.0

### Features

- **Markdown images in Live Preview** — standard same-vault Markdown images now render inline away from the cursor, with contained path resolution, safe fallbacks, semantic alt/title text, and cleanup of generated object URLs. Remote images and interactive resizing remain out of scope. (#151)
- **Safe internal-link page previews** — hover resolved Markdown links in Reading View, or hold Cmd/Ctrl while hovering rendered links in Live Preview, to inspect read-only note and heading previews without navigating away. (#153)
- **Editor-aware plugin commands** — hosted plugins can register `editorCallback` and `editorCheckCallback` commands across the command palette, hotkeys, guest hotkeys, and programmatic dispatch. Callbacks currently receive CM6's `EditorView`, not the complete Obsidian `Editor` adapter. (#154)
- **`FileManager.processFrontMatter` compatibility** — plugins can safely read, mutate, serialize, and persist note frontmatter with same-file calls serialized inside one renderer runtime. Coordination with direct vault writes, external writers, and host timestamp application remains partial. (#155)
- **Per-vault metadata scan cap** — a new Settings → Advanced control bounds body metadata scanning for very large notes, defaulting to 300 KB. Frontmatter remains indexed; headings, tags, links, and list items beyond the cap are intentionally skipped to control memory use. (#150)

### Bug Fixes

- **Lower peak memory during renderer fallback indexing** — metadata-cache persistence now streams bounded batches over IPC and prunes deleted rows afterward, avoiding a vault-sized duplicate payload when the background indexer is unavailable. Diagnostics now record fallback entry and its reason. (#149)
- **Responsive, cancellable Unlinked Mentions scans** — large and delimiter-heavy vaults now yield cooperatively to the renderer, cancel stale work, exclude valid frontmatter, and avoid caching partial results. (#152)

### Improvements

- Updated the README for the v0.11.0 feature set, settings, and explicit plugin-compatibility boundaries. (#156)
- Stabilized the Web Viewer bookmark release test by verifying persisted link identity independently from Chromium's asynchronous page-title event. Application behavior is unchanged. (#157)

### Notes

- Geode remains early alpha.
- macOS installers are ad-hoc signed but not notarized. On first launch, use Control-click → Open or the documented Gatekeeper workaround in the README.
- This release includes macOS DMG and ZIP builds for Apple Silicon and Intel.
