## Bug fixes

- **Web Viewer keeps Back/Forward history when reusing a tab.** Opening another URL in the same Web Viewer now preserves the live browser and its navigation history instead of recreating it. (#186)
- Rapid navigation, redirects, and delayed failures no longer replace a newer requested URL with an older one. A later navigation can also restore a Web Viewer after its browser process exits.

## Install

Download the Apple Silicon (`arm64`) or Intel macOS DMG/ZIP below. Builds are ad-hoc signed and not notarized; see the README for installation instructions.
