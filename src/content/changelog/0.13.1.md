## Bug fixes

- Web Viewer links using `target="_blank"` or `window.open()` now open in a tab within the originating tab group instead of creating a separate native window. Background tabs preserve your selection, including when you switch tabs while a page opens. (#181)

## Notes

- Popup destinations must use HTTP or HTTPS; unsupported schemes remain blocked.
- macOS installers are available for Apple Silicon and Intel. Builds are ad-hoc signed but not notarized; installation guidance is in the README.

## Verification

TypeScript, build, 1,764 unit tests, and 208 Electron E2E tests passed, including popup and background-selection regressions.
