## Bug fixes

- **Terminal plugin compatibility.** The filesystem adapter now supplies the missing `getFullPath` method, restoring command checks for the active file's parent folder. (#259)
- **Filesystem catalog objects publish atomically.** Concurrent readers now see either the previous complete object or the new complete object, never partially written bytes. This repairs a race found during release verification of the opt-in Node tooling; it does not change desktop sync or claim power-loss durability. (#260)
- **Sync planning shows measurable progress.** The local planning phase now displays processed-file counts and a percentage. Repeated failed attempts show an attempt number, so a restarted run no longer looks like one uninterrupted wait. Remote scans remain indeterminate when the provider cannot report a total. (#254)

## Developer foundations

- Added the bounded DSQL/private Blob feasibility harness and documented its publish/restore evidence and limits. (#257)
- Added an opt-in Node catalog adapter with atomic metadata publication, bounded retries and resource limits, and verified private Blob restore. It is available for in-repository tooling; this release does not enable cloud synchronization or connect the desktop app to a cloud backend. (#258)

## Downloads

macOS installers and ZIP archives are provided for Apple Silicon and Intel Macs, with auto-update metadata. Builds remain ad-hoc signed and are not notarized; see the README installation instructions if macOS blocks first launch.
