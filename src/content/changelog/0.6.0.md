## What's New in v0.6.0

### Features

- **Flexible workspace layouts** — move built-in and plugin views between the main area and sidebars, create vertically stacked sidebar groups, resize them independently, and restore the recursive layout across launches. (#77)
- **Interoperable JSON Canvas editor** — open and edit JSON Canvas 1.0 boards with text, file, link, and group cards; labeled edges; pan and zoom; and persistent drag/resize geometry. (#74)
- **Multi-window vault management** — use Manage vaults or the command palette to open recent or new vaults in isolated top-level windows. Selecting an already-open vault restores and focuses its existing window. (#76)
- **Local HTML in Web Viewer** — open `.html` and `.htm` files from a vault in the isolated Web Viewer with relative CSS, JavaScript, and image assets resolved correctly. (#75)

### Improvements

- Workspace persistence now migrates older flat layouts to the recursive v2 format.
- Built-in and plugin views share the same movable workspace-leaf model for better Obsidian compatibility.
- Missing recent vaults are filtered from vault management, while cancelled and invalid selections leave the current window untouched.

### Notes

- Canvas link cards render but do not open a browser yet, and file-card subpaths do not scroll to a referenced heading.
- macOS builds remain ad-hoc signed and unnotarized. Follow the first-launch instructions in the README if Gatekeeper blocks the app.
- Windows and Linux installers are not included in this release.
