## What's New in v0.8.1

This patch release brings Geode's everyday document and tab actions closer to
Obsidian's behavior while keeping those actions consistent everywhere they appear.

### Features

- **Immediate naming for new notes** — creating a note now selects its `Untitled`
  name immediately so you can type the real name without a separate rename step.
  Empty names and filename collisions safely restore the existing name and show
  feedback instead of leaving the file in a broken state. (#135)
- **Shared document actions** — tab right-click menus, the Markdown view's More
  options menu, File Explorer, and command-palette adapters now use one contextual
  action system for opening, renaming, moving, bookmarking, copying paths and links,
  revealing files, and deleting them. Explicit menus act on the exact file or tab
  that was clicked, including when the same file is open more than once. (#135)
- **Complete tab-management menus** — tabs now expose Close, Close others, Close
  right, and Pin/Unpin alongside document actions. Bulk closing stays within the
  clicked tab group and preserves pinned tabs. (#135)

### Improvements

- File Explorer and command integrations now share the same underlying behavior,
  reducing drift between UI surfaces while preserving existing public command IDs.
- ADR-0006 documents the contextual action architecture and targeting rules.

### Notes

- No migration steps or breaking changes.
- Existing vaults, plugins, themes, command IDs, and layouts remain compatible.
- macOS builds are ad-hoc signed but not notarized; see the README's Install section
  for the one-time Gatekeeper workaround.
