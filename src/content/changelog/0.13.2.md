## Bug fixes

- Fixed desktop community plugins failing to make network requests with `requestUrl()`. HTTP and HTTPS requests now run through Electron's main process, supporting request headers, text and binary bodies, redirects, and text, JSON, or binary responses. (#182)

## Notes

- Renderer Content Security Policy remains unchanged; raw renderer `fetch()` is still restricted.
- Browser and mobile networking behavior is unchanged. No migration or configuration changes are required.
- macOS installers are available for Apple Silicon and Intel. Builds are ad-hoc signed but not notarized.

## Verification

- TypeScript passed; 1,768 unit tests and 209 Electron end-to-end tests passed.
