## What's New in v0.10.3

### Features

- **Named tab collections** — organize related tabs into named, color-coded, split-local collections that can be reordered, collapsed, restored across launches, and managed from tab menus or the command palette. Collapsing a collection keeps its active document visible and gives the collection label a clear active state. ([#143](https://github.com/rbcodelabs/geode/pull/143))

### Improvements

- Collection controls support keyboard navigation, accessible names and state, reduced motion, and a distinct focus treatment that remains visible without producing a nested double outline.
- Workspace schema v3 migrates older layouts tolerantly, normalizes malformed collection metadata deterministically, prunes missing files safely, and preserves surviving collection state.
- Collection metadata remains intact when a workspace is opened and saved on mobile, while collection UI remains desktop-only.
- Tab collection styling is covered against Geode's light/dark themes and structural community-theme fixtures.

### Notes

- Collections belong to one main-area split. Moving a tab to another split removes its collection membership; pinned state remains independent.
- This release includes Phase 1 named tab collections only. Vertical/left-side tabs are not included.
- Release metadata was finalized in [#147](https://github.com/rbcodelabs/geode/pull/147).
- macOS installers are ad-hoc signed but not notarized; follow the first-launch instructions in the README.
