## Improvements

- **Minimal Theme Settings 9.0.0 now works on desktop.** Its toggles, dropdowns, sliders, theme preferences and font sizes render and persist across app restarts. Compatibility is certified for this exact plugin version; Geode's general Obsidian API baseline remains 1.8.0. (#177)
- **Safer community plugin updates.** Updates install the release that passed compatibility checks and validate its downloaded manifest before replacing installed files, preventing a newer incompatible release from slipping through during an update. (#177)

## Verification

Typecheck and build passed. The full suite passed 1,670 unit tests and completed 203 Electron tests: 202 passed directly and one Canvas test passed on retry. The real upstream Minimal Settings plugin passed settings and restart verification.

## Installation

Download the DMG or ZIP for Apple Silicon (`arm64`) or Intel from the assets below. macOS builds are ad-hoc signed, not notarized; see the README for first-launch instructions. This release does not certify Minimal Settings on mobile or versions newer than 9.0.0.
