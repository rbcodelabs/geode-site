## Bug fixes

- **Links open in the pane you clicked.** Clicking an internal link in an inactive split pane now opens the destination there without requiring you to focus the pane first. This includes links to Bases files and Cmd/Ctrl-clicks that open a new tab. (#256)
- **Plugin selection dialogs open correctly.** Fixed a missing keyboard-shortcut scope that caused some plugin dialogs, including Terminal's selection commands, to fail during construction. (#255)

## Downloads

macOS installers and ZIP archives are provided for Apple Silicon and Intel Macs, with auto-update metadata. Builds remain ad-hoc signed and are not notarized; see the README installation instructions if macOS blocks first launch.
