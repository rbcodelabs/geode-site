## What's New in v0.11.1

### Bug Fixes

- **Restored the right-sidebar toggle in split workspaces.** When the main workspace contained multiple resizable panes, the right-sidebar collapse/expand control could disappear. The control now remains available on the outermost pane, so Backlinks and other right-sidebar views can be collapsed and reopened normally. (#160)

### Notes

- No migration or configuration changes are required.
