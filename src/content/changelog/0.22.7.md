## What's new in v0.22.7

### Features
- **Ivory is built in.** The website-inspired green theme now ships with Geode for new and existing desktop vaults. Select **Settings → Appearance → Theme → Ivory**; no theme download or demo-vault copy is needed. Default remains unchanged, and a same-name vault theme takes precedence. (#263)
- **Find saved websites faster.** New Tab and Cmd/Ctrl+O search saved website bookmarks by title or URL, including bookmarks inside groups, and open the selection in Web Viewer. Existing file ranking and direct URL/search behavior are preserved. (#262)

### Bug fixes
- **Keep chat and companion previews separate.** A restored or rearranged workspace no longer opens a Design preview as another tab in its conversation pane. Existing tabs and pin state are preserved, and later opens reuse the separate companion pane. (#264)
- **Return to plugin views with Back.** When a picked file replaces a plugin pane, Back restores its saved view state—including an Agent Threads conversation—and Forward returns to the file. History remains session-only and per tab. (#261)
- **Preserve multi-window sync safety.** A successful refresh in one window can no longer acknowledge another window's pending refresh. A rejected Canvas refresh retains stale-writer protection. (#265)

### Verification improvements
- Wait for workspace restoration and fixture registration before testing plugin Back/Forward history. (#269)
- Isolate the local HTML fixture and wait for guest navigation before checking relative CSS, JavaScript, and images. (#267)
- Await Terminal plugin startup before verifying its registered commands. (#267)
- Wait for asynchronous project-association persistence in the Threads lifecycle test while retaining the exact safety assertion. (#265)
- Keep native-fullscreen UI testing opt-in via `npm run test:e2e:native-fullscreen`, so routine background verification does not take over the desktop. (#266)

### Notes
- macOS Apple Silicon and Intel builds are included. Builds are ad-hoc signed, not notarized; the existing Gatekeeper installation guidance still applies.
- Bundled Ivory is a desktop Electron feature; browser and Capacitor builds retain their existing vault-theme behavior.
- No migration is required. Experimental sync limitations remain unchanged; this patch does not enable a production cloud-sync service.
- Passkey work in #245 and #246 is not included.
