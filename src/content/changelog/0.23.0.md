# Geode v0.23.0

## Signed Apple Silicon releases

- macOS downloads are now Developer ID signed and notarized by Apple, with a stapled notarization ticket. (#272)
- Geode checks for updates and asks before downloading and restarting to install. Help → Check for Updates offers an on-demand check. (#272)
- The standalone installer verifies Geode's publisher and the downloaded app before replacement, preserves its signature, and restores the prior bundle if replacement fails. (#272)

## Compatibility and installation

- New macOS releases support Apple Silicon (arm64) only. Intel users can continue using their last compatible release.
- Users of earlier ad-hoc-signed builds must manually install this first signed release from the DMG to establish the update baseline.
- The command-line installer requires native arm64 Node.js 23.6 or newer.
- The signing pipeline passed a real arm64 packaging, notarization, stapling, Gatekeeper, and updater-manifest verification run. A real installed-version-to-next-version update cycle remains a rollout validation item.

## Developer changes

- Added an independently versioned headless SDK package with Node 22+ ESM, TypeScript declarations, and an immutable namespace-bound document store with verified content reads and writes. This desktop release does not publish the SDK to npm. (#268)
- Isolated Web Viewer regression fixtures to improve test reliability. (#270)
- Moved release history from the README to the website changelog and GitHub Releases. (#271)
